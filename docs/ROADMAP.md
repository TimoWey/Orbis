# Roadmap

| Phase | Ergebnis / Abnahme |
| --- | --- |
| 1. Basis | Versionen und Upstream-Commit pinnen, Lizenz prüfen, Fabric-Build |
| 2. Biom-/Grössenanalyse | Generator instrumentieren, Kandidaten prüfen, Normalgrösse begründet festlegen |
| 3. Weltfunktion | Periodische Overworld/Nether, festes 1:8, unverändertes End; Nähte/Persistenz prüfen |
| 4. Pflichtmods | Sodium + Lithium + Distant Horizons früh gemeinsam integrieren und testen |
| 5. Biom-UI | Fortschritt, Ergebnis je Dimension, Warnhinweis und Handlungsoptionen |
| 6. Konverter | Weltkopie, Vorschau, Schutzbereiche, Übergänge, Datenintegrität und DH-Cache |
| 7. Singleplayer-Release | Versionsmatrix, Regressionen und dokumentierte Grenzen |

Kein Terminversprechen. Pflichtmod-Tests begleiten die Entwicklung. Noch keine Simulation, kein Build und kein Spieltest durchgeführt.
